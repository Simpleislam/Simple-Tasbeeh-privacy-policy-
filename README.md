# Tasbeeh privacy policy

The privacy policy for the Tasbeeh app for Android, published as a single page (`index.html`).

To put it online, turn on GitHub Pages for this repository: **Settings > Pages > Build and deployment > Deploy from a branch > `main` / `(root)`**. The page will then be at:

https://simpleislam.github.io/Simple-Tasbeeh-privacy-policy-/

Use that address as the **Privacy policy URL** in the Google Play Console.
